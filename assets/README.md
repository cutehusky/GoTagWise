# GoTagWise icon

The icon combines Go lettering, struct braces and a colon on a cyan tag, plus a green validation check. It is drawn as an editable SVG with no embedded fonts or bitmap content.

- Production source: [pluginIcon.svg](../src/main/resources/META-INF/pluginIcon.svg), 40 × 40 with transparent padding, packaged in the plugin's META-INF directory.
- Preview/export: [gotagwise-icon.png](gotagwise-icon.png), 256 × 256 with transparency.

The same mark is used on light and dark backgrounds.
